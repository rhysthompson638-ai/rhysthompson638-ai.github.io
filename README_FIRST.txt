IMPORTANT BEFORE PUBLISHING
1. Open index.html in a browser and test it.
2. Search for hello@YOURDOMAIN.example in index.html and replace it with an email address you control.
3. Change any prices, offer terms, business claims and contact details to match what you can genuinely deliver.
4. The project planner is NOT a live AI model. It is a browser-based estimator. Do not advertise it as an autonomous AI builder yet.
5. The contact form uses mailto. It does not store or transmit leads to you unless the visitor sends the email.
6. Before collecting personal data through a live form, add an appropriate privacy notice and configure secure storage, access controls and retention.
7. Do not promise a customer a working integration until you have checked the relevant service, permissions and costs.

FREE HOSTING OPTION — GITHUB PAGES
1. Create a GitHub account.
2. Create a new PUBLIC repository named exactly: YOURUSERNAME.github.io
3. Upload index.html to the root of that repository.
4. Open repository Settings > Pages.
5. Choose Deploy from a branch, select main and /(root), then Save (if the option is shown).
6. Wait for GitHub Pages to publish. Your site address should be https://YOURUSERNAME.github.io
7. Reopen the published website on a phone and computer and test every link and form.

No paid custom domain is required. Free hosting availability and terms are controlled by GitHub and may change.
